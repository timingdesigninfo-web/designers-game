# デザイナーの発想

毎日ひとつのお題を、○△□だけで表現するデザイナー向けの発想ゲーム。

- 今日のお題は日本時間の日付から決まり、全員共通（`odai.js` の `EPOCH` が No.1）
- 作品はブラウザ内（localStorage）に保存
- 完成した作品は 1200×1200 の画像にして X へシェア（#デザイナーの発想）

ビルド不要の静的サイトです。`index.html` をそのまま配信すれば動きます。

## かんじクエスト（/kanji/）

小学4年生の漢字テスト練習アプリ。指で書いて、AIが丸つけする。

- `kanji/index.html` がアプリ本体、`api/kanji.js` がAI丸つけ（Claude API）
- Vercel の環境変数 `ANTHROPIC_API_KEY` が必要
- 使いすぎ防止：アプリ側で1日5回、サーバー側でサイト全体1日20回（`KANJI_AI_PER_DAY`）。Anthropic の管理画面で月の上限金額も設定する
